☀️ EasySun
Muitas propostas de energia solar prometem retornos financeiros (payback) irrealistas ou omitem riscos técnicos. O EasySun surge com o objetivo de trazer transparência ao mercado fotovoltaico, auxiliando o consumidor final a tomar decisões baseadas em dados técnicos reais e não apenas em promessas comerciais.
O projeto permite a análise detalhada de orçamentos, verificando a qualidade dos componentes, a estimativa de geração e o tempo real de retorno sobre o investimento.

🔍 Sobre o projeto
Desenvolvido como uma solução para o mercado de energia solar brasileiro, o EasySun propõe uma alternativa para consumidores que se sentem inseguros ao receber orçamentos complexos. Sem uma análise técnica, muitos clientes acabam adquirindo sistemas com componentes de baixa qualidade ou expectativas de geração que não condizem com a realidade geográfica e técnica.
Baseado na extração inteligente de dados de arquivos PDF ou inserção manual, a plataforma cruza as informações do orçamento com bases de dados técnicos para gerar um Veredito Transparente.

🛠️ Como Funciona
A plataforma segue um fluxo simples e intuitivo para o usuário:
=Envie o Orçamento: O usuário faz o upload do PDF recebido pela empresa solar ou insere os dados manualmente.
-Análise Inteligente: Nosso sistema utiliza IA para extrair dados e verifica componentes, potência e cálculos de payback contra parâmetros técnicos reais.
-Veredito Transparente: O usuário recebe um relatório completo com um Termômetro de Confiança e um comparativo detalhado dos riscos e benefícios.
