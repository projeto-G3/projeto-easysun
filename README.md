☀️ EasySun — Solar Truth Analyzer

Descubra a verdade sobre seu orçamento solar.
EasySun é uma plataforma web que permite ao consumidor analisar orçamentos de energia solar recebidos de empresas instaladoras, identificando se o payback prometido é real, se os componentes são de qualidade e se o preço é justo — com base em dados técnicos reais.

🚀 Funcionalidades:
📄 Upload de Orçamento (PDF) — Envie o PDF do orçamento recebido e a IA extrai os dados automaticamente
✏️ Preenchimento Manual — Insira os dados do orçamento manualmente pelo formulário
🤖 Análise Inteligente — Verificação de componentes, geração estimada e payback real
📊 Veredito Transparente — Relatório com Termômetro de Confiança e comparativo detalhado

🛠️ Tecnologias Utilizadas:
Frontend (React + Vite)
Estilização (Tailwind CSS)
Build/Deploy (Lovable.dev)
Versionamento (Git + GitHub)
IA / Backend (Python - em desenvolvimento)
